## Reproduction and boundaries

1. Check out the audited revision in a clean worktree. Use Node 20 and pnpm 9.12.0. For a deep Windows worktree with legacy path limits, set `npm_config_virtual_store_dir_max_length=75` for the locked install. Run `pnpm db:generate`, then `pnpm build`, `pnpm typecheck`, `pnpm lint` and `pnpm test` individually so lint failure does not suppress later checks.
2. Start disposable PostgreSQL and Redis-compatible instances on dedicated loopback ports with empty data and synthetic credentials. The audited host used an isolated native PostgreSQL 17.10 cluster and installed Memurai 8.1.240.0 because Docker was unavailable. The repository's [Compose file](../../docker-compose.yml) describes Postgres 15 and Redis 7. Neither its exact image pair nor the hosted CI image pair ran in G0.
3. Configure both database URLs to the isolated cluster and `REDIS_URL` to the disposable cache. Use `NODE_ENV=development`, synthetic distinct access/refresh secrets, a test encryption key, synthetic Meta webhook secrets and the local frontend URL. Set `HAIKU_FALLBACK_ENABLED=false` and leave provider credentials unset. Write an LF-terminated root fixture `.env` with the synthetic `META_WEBHOOK_SECRET` for the legacy smoke reader. Never copy the original checkout's environment file.
4. Apply migrations and confirm status. Start the API and workers with `node --import tsx src/server.ts` in `apps/api`. Use `API_URL` for the isolated smoke target. Set `API_PROXY_TARGET` to the same local URL and start Vite on a dedicated port. Verify health and frontend/proxy before interpreting end-to-end results.
5. The G0 runtime used a Node preload to deny non-loopback fetches and socket targets and only used synthetic tenants and rows. The worker's live credential rejection path was deliberately unavailable. The temporary services were stopped and the generated worktree `.env` removed. Logs and fixture clusters are local-only. Production systems, customer data, live credentials and paid services were outside the audit.

Live Meta, Paystack, model providers, email, media, deployed routing, production restore, migration from a populated database and real concurrent recovery are unverified. The mocked Vitest pipeline and synthetic smoke provide different coverage. See the [operator assessment](operators.md) and [G1 register](../milestones.md) for tests required to close the gaps.
