# G0 defect register

**P0** blocks a production-grade rollout because it can lose accepted business work, misstate cash or bypass access control. **P1** requires a bounded fix or a verified mitigation before enabling the affected workflow. **P2** is a follow-up. Evidence labels distinguish a local reproduction, a test that encodes existing behavior, an inspected source path, and an unverified deployment or concurrency scenario.
